# Исходники курсов

Сюда складываются Word-файлы (.docx) с материалами курсов — только для просмотра
при разработке. На сайт они не попадают: уроки вносятся вручную через админку
(раздел «Курсы» → «Уроки»).

Сами .docx в git не коммитятся (см. .gitignore), чтобы не раздувать репозиторий.

Удобная раскладка: одна папка на курс, внутри — файлы уроков, например
`content/courses/osnovy-very/01-urok.docx`.
