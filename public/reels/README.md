# Папка для вертикальных видео (Instagram Reels)

Поместите в эту папку 4 вертикальных видео для блока рилсов на главной странице:

- `reel-1.mp4` — Первое видео (например, воскресное богослужение)
- `reel-2.mp4` — Второе видео (например, слово пастора или проповедь)
- `reel-3.mp4` — Третье видео (например, молодёжное служение)
- `reel-4.mp4` — Четвёртое видео (например, жизнь общины или свидетельства)

### Требования к видео:
- **Формат:** MP4 (кодек H.264 / AAC)
- **Соотношение сторон:** вертикальное 9:16 (1080×1920 или 720×1280)
- **Длительность:** от 10 до 60 секунд
- **Оптимизация:** желательно сжать через Handbrake или любой онлайн-компрессор до 5–15 МБ на видео для быстрой загрузки.

По желанию можно положить статичные обложки с теми же именами:
`reel-1.jpg`, `reel-2.jpg`, `reel-3.jpg`, `reel-4.jpg`.
