# Папка для вертикальных видео (Instagram Reels)

Блок рилсов на главной странице показывает 4 видео из этой папки. У каждого видео
есть обложка с тем же именем — она видна сразу, пока само видео не загрузилось:

- `reel-1.mp4` + `reel-1.jpg`
- `reel-2.mp4` + `reel-2.jpg`
- `reel-3.mp4` + `reel-3.jpg`
- `reel-4.mp4` + `reel-4.jpg`

Обложка обязательна: без неё карточка остаётся пустой, пока видео не начнёт играть.

### Требования к видео

- **Формат:** MP4 (кодек H.264 / AAC)
- **Размер кадра:** вертикальный 9:16, 540×960 — карточка на сайте не шире 300 px,
  большее разрешение только утяжеляет страницу
- **Длительность:** от 10 до 60 секунд
- **Вес:** 3–6 МБ на видео

### Как подготовить файл

Нужен [ffmpeg](https://ffmpeg.org/). Сжать исходник из Instagram:

```bash
ffmpeg -i исходник.mp4 -vf scale=540:960:flags=lanczos \
  -c:v libx264 -preset veryslow -crf 30 -pix_fmt yuv420p \
  -c:a aac -b:a 56k -movflags +faststart reel-1.mp4
```

Сделать обложку из кадра видео (`-ss 2` — секунда, с которой взять кадр;
подберите так, чтобы кадр не попал на затемнение или переход в начале):

```bash
ffmpeg -ss 2 -i исходник.mp4 -frames:v 1 -vf scale=540:960:flags=lanczos -q:v 4 reel-1.jpg
```

### Видео для страницы молодёжи

Страница «Молодёжь» показывает такой же блок со своими видео из папки `public/reels/youth/`
(`reel-1.mp4` + `reel-1.jpg` … `reel-4.mp4` + `reel-4.jpg`, требования те же).
Чтобы заменить видео, положите новый файл с тем же именем и сделайте к нему обложку.
Если видео станет больше или меньше четырёх — поправьте список `YOUTH_REELS`
в `src/app/(frontend)/[locale]/(site)/youth/page.tsx`.
